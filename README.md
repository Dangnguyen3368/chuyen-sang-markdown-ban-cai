# Chuyển sang Markdown — by iFix Laptop

Phần mềm chuyển **PDF, Word, Excel, PowerPoint, ảnh, trang web...** sang **Markdown (.md)**, dạng chữ mà ChatGPT, Claude và các AI khác đọc tốt nhất. Đọc được cả **PDF scan và ảnh chụp** (17 thứ tiếng, tự nhận ngôn ngữ), tự lưu ảnh các trang có hình vẽ để AI xem lại khi cần. Chạy trên Windows, tài liệu xử lý ngay trên máy, không gửi lên mạng.

## Tải về

**[⬇ Tải file cài đặt mới nhất](https://github.com/Dangnguyen3368/chuyen-sang-markdown-ban-cai/releases/latest/download/ChuyenSangMarkdown-CaiDat.exe)** (bấm là tải ngay, khoảng 200 MB).

Yêu cầu máy:

- Windows 10 hoặc 11 (64-bit), khoảng 700 MB ổ cứng.
- Không cần cài thêm phần mềm nào. Không cần Internet khi chuyển đổi, chỉ cần mạng khi cập nhật.

## Cài đặt (khoảng 1 phút)

1. Bấm đúp file **ChuyenSangMarkdown-CaiDat.exe** vừa tải.
2. Nếu Windows hiện **"Windows protected your PC"**: bấm **More info**, rồi **Run anyway**. Đây là cảnh báo bình thường với phần mềm mới, không phải virus.
3. Bấm **Tiếp**, **Cài đặt**, rồi **Hoàn tất**. Biểu tượng **Chuyển sang Markdown** có trên Desktop và Start Menu.

## Cách dùng

1. Mở **Chuyển sang Markdown**, bấm **Chọn file...** hoặc **Chọn thư mục...**
2. Bấm **▶ Chuyển đổi**. File `.md` nằm ngay cạnh file gốc (hoặc thư mục bạn chọn).
3. Gửi file `.md` cho AI. Trang nào có hình thì trong `.md` có dòng `xem hình: ...`, ảnh trang đó nằm trong thư mục `<tên file>_hinh` cạnh file `.md`. Muốn AI xem hình, kéo ảnh trang đó vào khung chat cùng file `.md`.

Mẹo:

- Để nguyên ô **Tự nhận ngôn ngữ** là được, phần mềm tự biết tài liệu tiếng Việt, Anh, Pháp, Trung, Nhật, Hàn, Nga...
- Tài liệu ngắn (vài chục trang) có thể gửi thẳng PDF cho AI. Phần mềm này hữu ích nhất với sách dày, sách scan, hoặc khi cần chuyển cả thư mục.
